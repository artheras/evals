# Evaluation Results & Baselines

This directory stores **aggregate** evaluation records and reproducible baseline summaries—never raw model transcripts, private holdout questions, or confidential logs.

## Categories

1. **Public Catalog Runs (`summary.json`)**:
   - Generated by `aria-evals run` against the 30-task public catalog (`evals/suites/public.yaml`) on the pinned engine in [`registry.json`](../registry.json).
   - Compare any two runs or render a Markdown/JSON leaderboard table across multiple archived summaries:
     ```bash
     aria-evals diff results/<baseline>.json results/<candidate>.json
     aria-evals leaderboard results/
     ```
2. **Upstream Engine CI Reference Runs**:
   - Aggregate metrics from [`artheras/aria-code`](https://github.com/artheras/aria-code) scheduled evaluation workflows, recorded with explicit scope, sample sizes, and known limitations.
   - [Evals #14 — Coding & Operations Baseline (`google/gemini-3.5-flash`, `repeat=1`)](aria-code-evals-14.md)

## Reporting Standards

Every published record should disclose:
- Exact model, provider, `repeat` count, and engine revision/run URL.
- Both overall completion rate and any unscored/skipped suites (e.g. holdout).
- Known failure modes (e.g. orchestration early-stops vs. logic errors) and comparison baselines needed.
